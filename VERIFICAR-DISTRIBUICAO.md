## Premiere

- Guia estável: https://github.com/CriativosdoFuturo/trombino-kit-edicao-ia/blob/main/INSTALAR-PREMIERE.md
- Prompt: https://raw.githubusercontent.com/CriativosdoFuturo/trombino-kit-edicao-ia/main/PROMPT-PREMIERE.txt
- Pacote atual desta revisão: `premiere-setup-1.3.5.zip`; checksum: `premiere-setup-1.3.5.sha256`.
- Alias: `premiere-mcp-instalador-latest.zip`; checksum: `premiere-mcp-instalador-latest.sha256`.
- Os checksums terminam em **.sha256**, não **.zip.sha256**. Leia sempre a versão indicada pelo guia; não mantenha a versão deste documento fixada no monitor para sempre.
- Verifique HTTP, tamanho, formato ZIP e o SHA-256 calculado dos bytes baixados. O alias deve ser idêntico ao pacote atual. Leia os pins nos bootstraps e no prompt: precisam apontar para o mesmo pacote/hash.
- Baixe o script `instalar-premiere-mac.sh` como bytes e confirme ausência de CRLF e BOM. Texto renderizado pelo GitHub não prova o formato de quebra de linha.
- Hash correto comprova correspondência com a publicação, não ausência de malware, instalação bem-sucedida ou todas as funções de edição.

## Como informar o resultado

Informe data, URL exata, versão/revisão consultada, status HTTP ou erro observado e a evidência. Uma falha de uma ferramenta de pesquisa ou de uma rota na nuvem não prova indisponibilidade para alunos. Confirme por outra leitura pública permitida antes de concluir; não contorne bloqueios explícitos nem desative TLS. Se não conseguir confirmar, registre como inconclusivo.

Separe: (1) funcionamento dos links e integridade; (2) compatibilidade documentada; (3) instalação e conexão real, não verificadas pelo monitor. Notifique mudanças relevantes e problemas acionáveis; não repita alertas iguais como se fossem incidentes novos. Não afirme que uma correção foi publicada antes de conferir os arquivos públicos.
